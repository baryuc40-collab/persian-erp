# STORY-057: فیلد کد پستی و تلفن همراه

## روایت
به‌عنوان کاربر ثبت مشتری، می‌خواهم کد پستی و تلفن همراه با یک قالب یکسان ذخیره شوند تا جست‌وجو و پیامک درست کار کنند.

## معیار پذیرش
- **Given** فیلد «تلفن همراه» **When** `+98 912 345 6789`، `00989123456789`، `9123456789` یا `۰۹۱۲۳۴۵۶۷۸۹` وارد شود **Then** `09123456789` ذخیره می‌شود
- **Given** همان فیلد **When** شماره‌ای که با `09` شروع نشود یا ۱۱ رقم نباشد ذخیره شود **Then** با پیام «شماره‌ی تلفن همراه معتبر نیست» رد می‌شود
- **Given** فیلد «کد پستی» **When** `13185-34567` وارد شود **Then** `1318534567` ذخیره و به شکل `13185-34567` نمایش داده می‌شود
- **Given** همان فیلد **When** کمتر یا بیشتر از ۱۰ رقم یا با رقم ۰ در ابتدا ذخیره شود **Then** رد می‌شود

## یادداشت فنی
- کد پستی ایران ۱۰ رقم است و رقم اول آن صفر نیست. قاعده‌های دقیق‌تر شرکت ملی پست (نبود ۰ و ۲ در پنج رقم اول) منبع رسمی روشنی ندارند؛ اگر لازم شد، استوری جدا.
- الگوی مشترک اپیک.
