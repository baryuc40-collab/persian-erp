# STORY-016: خط لوله‌ی ترجمه‌ی دسته‌ای با Claude

## روایت
به‌عنوان عامل ترجمه، می‌خواهم با یک دستور کلیدهای ترجمه‌نشده‌ی یک پکیج را با واژه‌نامه ترجمه کنم، تا هر PR ترجمه سریع و یکدست باشد.

## معیار پذیرش
- **Given** نام یک پکیج **When** `yarn i18n:translate <package>` اجرا شود **Then** فقط کلیدهای ترجمه‌نشده ترجمه و در فایل fa-IR نوشته می‌شوند
- **Given** خروجی ترجمه **When** ابزار تمام شود **Then** `check:i18n` خودکار اجرا می‌شود و کلیدهای خطادار دوباره ترجمه یا گزارش می‌شوند
- **Given** کلید API نیست **When** ابزار اجرا شود **Then** پیام روشن فارسی می‌دهد و چیزی را خراب نمی‌کند

## یادداشت فنی
- Claude API با مدل Sonnet، واژه‌نامه و راهنمای سبک در بخش ثابت پرامپت با prompt caching؛ برای حجم بالا Batch API
- کلید API فقط از متغیر محیطی `ANTHROPIC_API_KEY`؛ هرگز در مخزن
- ترجمه‌ی کلیدهای موجود عوض نمی‌شود مگر با `--force`

## پرسش‌های باز
- Batch API هنوز پیاده نشده؛ ابزار دسته‌ها را پشت سر هم با Messages API و prompt caching می‌فرستد. اگر حجم یا هزینه مشکل شد، در استوری جدا اضافه شود.
- چون کلید API در دسترس نیست، حالت `--export`/`--import` اضافه شد تا عامل در جلسه ترجمه کند و همان بررسی‌ها اجرا شود.

## آزمون
- آزمون واحد با پاسخ ساختگی API (بدون تماس واقعی)
