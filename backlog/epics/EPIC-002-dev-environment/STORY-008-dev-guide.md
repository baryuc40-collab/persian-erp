# STORY-008: راهنمای اجرا و آماده‌سازی جلسه‌های ابری

## روایت
به‌عنوان عامل هوش مصنوعی در یک جلسه‌ی ابری Claude، می‌خواهم وابستگی‌ها و پایگاه داده خودکار آماده شوند، تا بتوانم تغییرم را واقعاً اجرا و آزمون کنم و فقط کد ننویسم.

## معیار پذیرش
- **Given** `docs/dev/getting-started.md` **When** یک توسعه‌دهنده‌ی تازه آن را دنبال می‌کند **Then** برنامه را با Docker یا بدون Docker اجرا می‌کند
- **Given** یک جلسه‌ی ابری Claude روی این مخزن **When** جلسه شروع می‌شود **Then** یک SessionStart hook وابستگی‌ها را نصب می‌کند و دستور اجرای آزمون آماده است
- **Given** `CLAUDE.md` **When** عامل آن را می‌خواند **Then** دستورهای اجرا، build و آزمون در آن آمده است
