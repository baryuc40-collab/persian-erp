# واژه‌نامه‌ی فارسی NocoBase

`fa-IR.csv` منبع حقیقت معادل‌های فارسی است. همه‌ی ترجمه‌ها (انسانی و هوش مصنوعی) باید از آن پیروی کنند.

- **وضعیت:** تأیید موقت صاحب پروژه (۱۹ مهر ۱۴۰۵) برای شروع ترجمه. در ۲۰ مهر ۱۴۰۵ به درخواست صاحب پروژه یک بازبینی کیفی کامل انجام شد (STORY-011): ۱۲ معادل اصلاح و ۲۱ ردیف افزوده شد و ترجمه‌های وابسته هم به‌روز شدند.
- **منبع انتخاب واژه‌ها:** پرتکرارترین واژه‌ها و ترکیب‌ها در ۴٬۴۸۳ کلید یکتای فایل‌های `en-US.json` و `zh-CN.json` در NocoBase v2.2.22، به‌علاوه‌ی اصطلاحات پایه‌ی رابط کاربری.
- **ستون‌ها:** `en` اصطلاح انگلیسی (اگر یک واژه در دو معنا آمده، معنا در پرانتز است)، `fa` معادل فارسی، `category` حوزه، `note` توضیح یا هشدار.

## تصمیم‌های بازبینی‌شده

صاحب پروژه در ۱۹ مهر ۱۴۰۵ این موارد را تعیین کرد (بقیه‌ی واژه‌نامه هنوز پیش‌نویس است):

| انگلیسی | معادل نهایی | پیش‌نویس قبلی |
| --- | --- | --- |
| Collection | مجموعه | جدول داده |
| Action | اکشن | عملیات |
| Trigger | رویداد شروع | آغازگر |
| Node | نود | گره |
| Plugin | پلاگین | افزونه |
| Import / Export | ورود داده / خروجی گرفتن | درون‌ریزی / برون‌بری |
| Popup | پاپ‌آپ | پنجره‌ی بازشو |
| Permission / License | دسترسی / مجوز | (بدون تغییر) |
| Todo | کارتابل | (بدون تغییر) |

ترکیب‌های وابسته هم هم‌سو شدند (مثلاً «مجموعه‌ی درختی»، «تنظیمات اکشن»، «نودهای بالادستی»، «مدیریت پلاگین‌ها»).
