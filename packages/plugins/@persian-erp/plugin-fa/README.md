# @persian-erp/plugin-fa

پلاگین فارسی‌سازی NocoBase. فعلاً فقط اسکلت است (STORY-006): در هر دو کلاینت (legacy و modern) یک Provider خالی ثبت می‌کند که در فازهای بعد جهت راست‌به‌چپ، فونت Vazirmatn و تقویم جلالی به آن اضافه می‌شود.

- build: `yarn build @persian-erp/plugin-fa`
- آزمون: `yarn test packages/plugins/@persian-erp/plugin-fa`
